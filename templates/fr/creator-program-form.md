# Programme créateurs

> Rejoindre le programme créateurs

Tu crées du contenu sur notre jeu ou notre communauté ? Clique sur Postuler pour rejoindre le programme créateurs.

Ready-to-use form from Toscio's templates (/toscio setup). Use case: https://toscio.com/fr/cas-usage/programme-createurs/?utm_source=github&utm_medium=templates

1. **Ton nom de créateur** _(short text)_
2. **Lien vers ta chaîne principale** — Twitch, YouTube, TikTok… le lien direct vers ta chaîne. _(short text)_
3. **Nombre d'abonnés ou viewers moyens** _(short text)_
4. **Ton rythme de publication** _(short text)_
5. **Quel contenu veux-tu faire avec nous ?** _(long text)_
6. **Tes autres réseaux** _(short text, optional)_
7. **Pourquoi ce programme ?** _(long text, optional)_
