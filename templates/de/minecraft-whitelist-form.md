# Minecraft-Whitelist

> Tritt dem Minecraft-Server bei

Der Server hat eine Whitelist. Klicke auf Bewerben und das Team fügt dich hinzu, sobald deine Bewerbung angenommen ist.

Ready-to-use form from Toscio's templates (/toscio setup). Use case: https://toscio.com/de/anwendungsfaelle/minecraft-whitelist/?utm_source=github&utm_medium=templates

1. **Dein Minecraft-Name** — Genau wie im Spiel, inklusive Groß- und Kleinschreibung. _(short text)_
2. **Java oder Bedrock?** _(short text)_
3. **Dein Alter** _(short text)_
4. **Warum willst du beitreten?** _(long text)_
5. **Was willst du auf dem Server machen?** — Bauen, Redstone, Handeln, Erkunden… _(long text)_
6. **Auf welchen Servern warst du schon?** _(short text, optional)_
7. **Wie hast du den Server gefunden?** _(short text, optional)_
