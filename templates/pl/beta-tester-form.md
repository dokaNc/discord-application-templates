# Betatesterzy

> Zostań betatesterem

Szukamy testerów następnej wersji. Kliknij Złóż podanie: wybrane osoby dostaną dostęp jako pierwsze.

Ready-to-use form from Toscio's templates (/toscio setup). Use case: https://toscio.com/pl/zastosowania/betatesterzy/?utm_source=github&utm_medium=templates

1. **Twoja platforma** _(short text)_
2. **Twój sprzęt lub urządzenie** — Procesor, karta graficzna, model telefonu… _(short text)_
3. **Godziny testów w tygodniu** _(short text)_
4. **Twoje doświadczenie w testowaniu** — Poprzednie bety, zgłoszenia błędów, podobne gry. _(long text)_
5. **Dlaczego chcesz testować?** _(long text)_
6. **Twój główny język** _(short text, optional)_
7. **Link do twojej opinii lub raportu** — Opcjonalnie: zgłoszenie błędu lub recenzja, którą napisałeś. _(short text, optional)_
