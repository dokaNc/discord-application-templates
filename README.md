# Discord application templates

Free, copy-and-paste templates for Discord servers: **staff and mod application questions**, **ready-made application
forms** (member applications, partnership requests, esport tryouts, creator programs, beta testers, whitelists…), a
**ban appeal template**, **server rules** and **welcome messages**. Use them in any form tool, application bot, rules or
welcome channel. No credit needed.

Every template comes as Markdown (to read and copy) and JSON (to import into your own tools), in 8 languages: English,
French, Spanish, Brazilian Portuguese, German, Turkish, Polish and Russian.

## Tips for Discord forms

- **Keep it short.** 5 to 15 questions is enough. Good applicants give up on 30-question forms.
- **Ask scenario questions.** “Two members are arguing in public chat: what do you do?” tells you more than “Why do you want to be staff?”.
- **Mind Discord's limits.** A native Discord form (modal) shows 5 questions at a time, and a question title is limited to
  45 characters. Put the detail in the description line under the question.
- **Use a checkbox for the rules.** A required “I have read the server rules” checkbox keeps your text questions for real answers.

## JSON format

Question lists, rules and welcome messages:

```json
{
  "title": "Discord Staff Application Questions: 58 Mod Questions to Copy",
  "language": "en",
  "source": "https://toscio.com/guides/discord-staff-application-questions/",
  "sections": [
    { "title": "About the applicant", "items": ["How old are you?", "What is your time zone?"] }
  ]
}
```

Ready-made forms:

```json
{
  "title": "Member application",
  "language": "en",
  "source": "https://toscio.com/use-cases/member-applications/",
  "questions": [
    { "label": "Your age", "type": "short text", "required": true }
  ]
}
```
